# Sportwetten-Rechner

Rechner für Sportwetten mit Bonus-Wetten (Gratiswette, risikofrei, Quotenboost), schaltbarer Wettsteuer und Optimierung des Mindestgewinns.

## Befehle

- `npm install` – Abhängigkeiten installieren
- `npm run dev` – Entwicklungsserver
- `npm test` – Tests
- `npm run build` – Typprüfung und Produktions-Build

## Aufbau

- `src/core/` – Rechenkern ohne UI-Bezug, mit Tests
- `src/ui/` – Oberfläche (Preact)

Entscheidungen und Planung stehen im J.A.R.V.I.S-Vault unter `1 Projects/Sportwetten-Rechner/`.
